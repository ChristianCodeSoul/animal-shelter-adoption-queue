# Animal Shelter Adoption Interest Queue

https://animal-shelter-adoption-queue.vercel.app


Vanilla JavaScript Adoption Interest Queue for Animal Shelter staff, with validation, search, loading states, accessibility, and XSS-safe data handling.

## Overview

This project is a lightweight adoption interest management interface designed for animal shelter staff.

It replaces a basic paper/Excel-based workflow with a simple browser-based queue where staff can add, search, review, and remove adoption interests.

## Features

- Add new adoption interest records
- Applicant and animal information tracking
- Search by applicant name, animal name, or phone number
- Form validation with clear error messages
- Empty queue and empty search states
- Loading indicator for simulated slow network operations
- Responsive layout for desktop, tablet, and mobile
- Keyboard-friendly and accessible form controls
- ARIA attributes for improved accessibility
- XSS-safe text handling
- Simulated analytics/telemetry logging
- In-memory state management using Vanilla JavaScript

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- DOM Manipulation

No frameworks or external libraries are used.
